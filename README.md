# Siva G Portfolio

React portfolio built with Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Deployment

Deploy this repository with any static hosting provider using:

- Build command: `npm run build`
- Output directory: `dist`
- Node.js: 18 or newer

For a continuous deployment setup, connect the repository to Vercel, Netlify, or another Vite-compatible static host and use the settings above. Public files such as images, certificates, and the resume are copied into the generated output automatically.
